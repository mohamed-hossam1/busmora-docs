# Documentation Templates

Copy these starting templates when creating new documentation:

- [[Task Record Template]] — Standard per-task record in `02 - Tasks/<JIRA-KEY>/Task.md`.
- [[Research Template]] — Exploration and dual search findings in `02 - Tasks/<JIRA-KEY>/research.md`.
- [[Benchmark Template]] — Empirical tool evaluation in `02 - Tasks/<JIRA-KEY>/benchmark.md`.
- [[Feature Overview Template]] — Canonical business capability overview in `03 - Features/<feature-name>/Overview.md`.

Adapt templates to the task. Delete instructional comments as they are answered; do not leave placeholder text in active documentation.
