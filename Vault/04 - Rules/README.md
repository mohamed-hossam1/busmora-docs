# Global Rules

Rules define **what every team member must do**. Keep these global and team-wide. Reusable instructions for how to perform a task belong in `03 - Skills/`.

## Initial rules

- [[End-to-End Task Execution Guide|End-to-End Task Execution Guide]] — Standard protocol for executing any task from Jira pickup to PR creation using Jira, Vault, and the unified skills suite.
- [[Documentation Lifecycle|Documentation Lifecycle]] — Two-write Vault documentation lifecycle and Jira status transitions.
- [[Vault Conventions|Vault Conventions]] — Global rules for Vault directory structure, boundaries, and canonical locations.

Add and agree on additional rules with the team before treating them as mandatory.
